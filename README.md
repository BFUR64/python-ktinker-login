# Python Tkinter Login Form

## Project Description
This project is a desktop login application developed using Python and Tkinter. The program accepts a username and password, checks the entered details, and displays a message depending on the result

## Features
- Username and password input
- Password characters are hidden while typing
- Login validation
- Successful login notification
- Failed login notification
- Customized login form
